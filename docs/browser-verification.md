## 實際匯入、編輯與下載

自行建立一秒立體聲 WAV，左右聲道振幅分別為 0.25 與 0.5。瀏覽器匯入後，使用欄位選取 **0.2 至 0.8 秒**，設定淡入 **0.05 秒**、淡出 **0.1 秒**，峰值正規化為 **−3 dBFS**，實際下載 WAV。

以 Python 標準 `wave`／`struct` 讀回下載檔：

| 項目 | 結果 |
| --- | --- |
| 編碼 | PCM16、立體聲 |
| 工作取樣率 | 44,100 Hz |
| 取樣格數 | 26,460 |
| 長度 | 0.6 秒 |
| 取樣峰值 | −3.00036 dBFS，含 PCM16 量化誤差 |
| 第一格／最後一格 | 兩個聲道均為 0，符合淡入淡出 |
| 中間取樣的左右比 | 約 0.50002，保留原先聲道平衡 |

## 互動與錯誤處理

- 預設繁體中文；切換英文、再切回繁中，保留已設定的淡入時間。
- 波形把手按 Shift + 方向鍵，起點精確前進 0.1 秒。播放／停止按鈕成功切換狀態；未做真實喇叭音質認證。
- 輸入超出長度的終點後按 Enter，欄位還原至有效範圍，並顯示繁中錯誤。
- 匯入非音訊內容的 `.wav`，顯示媒體長度讀取錯誤，保留原先音軌。
- 匯入 91 秒 WAV，顯示超出長度限制，保留原先音軌。
- 390 × 844 px 配置：編輯控制採單欄、A/B 按鈕位於工作台內、沒有水平溢出；1440 px 桌面配置另行檢視。截圖來自實際頁面。

## 邊界

核心測試另外驗證 WAV 標頭、聲道交錯、單格淡入淡出、靜音、裁切、過期 worker 請求及中繼資料清理。獨立數值檢查確認處理後預聽使用的量化樣本與 WAV 一致；實際播放硬體可能再重取樣。

本次沒有完整 Safari／Firefox、手機實機、螢幕閱讀器或高記憶體壓力測試。瀏覽器解碼器可能改變取樣率，且無法在解碼開始後強制中止；請參閱 README 的限制。
